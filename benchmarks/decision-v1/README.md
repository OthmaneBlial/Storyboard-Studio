# Decision benchmark v1

`suite.json` contains 10 synthetic decision briefs. It contains no user data,
private deck content, or retrieved evidence. The fixture is dedicated under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/); generated code
and benchmark tooling remain under the repository's MIT license.

The dated `baseline/` directory contains every raw story, diagnostic, evidence
report, layout report, provider receipt, rubric result, and editable PPTX used
by the published summary. See [`docs/BENCHMARK.md`](../../docs/BENCHMARK.md) for
the rubric, reproduction command, regression policy, and limitations.
