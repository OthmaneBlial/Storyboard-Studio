# Release demo checklist

For every material workflow release, refresh the Pages showcase and attach a
short, privacy-safe proof asset:

- show the private decision-brief example;
- show one inline edit and one block/layout change;
- export the native PPTX and select a text box in a viewer;
- include an accessible transcript and descriptive alt text;
- link the exact fixture, commit, and viewer matrix.

The canonical transcript is [`demo.md`](demo.md); the public gallery is
[`GALLERY.md`](GALLERY.md). Neither uses private client material.
