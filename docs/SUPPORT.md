# Support

Report a concrete native behavior with the version, OS/architecture, exact command
or desktop steps, expected result and a minimal synthetic input. Redact local paths
and never upload private decks, API keys or source documents.

Run `storyboard validate deck.pptx` for package problems and
`storyboard verify deck.receipt.json` for bundle consistency. State the actual
viewer/version separately when reporting rendering behavior. Sources and author
confirmation do not certify factual truth. See the format and security contracts.

For vulnerabilities, use the private GitHub security advisory flow. Do not disclose
sensitive reports publicly. The owner has cleared the historical issue/PR queue;
new reports should provide a reproducible problem rather than general backlog items.
