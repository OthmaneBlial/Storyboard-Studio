# Sources, evidence, and speaker notes

Each content slide may carry up to six author-supplied source references. The
browser exposes every supported field and every source, including claim links,
excerpt, owner, public URL or relative local reference, checked date, optional
license, and explicit review status.

Storyboard Studio never fetches a source URL and never turns URL presence into
verification. Only the author can choose `author-checked`, and the schema then
requires an owner, checked date, and locator. Missing owners, unlinked entries,
and unresolved URLs remain visible in Evidence coverage and the Doctor.

All source fields are copied into native PowerPoint notes. An optional native
citations appendix contains author-checked entries only. See
`docs/EVIDENCE_WORKFLOW.md` for the complete preservation and threat-model
boundary.
