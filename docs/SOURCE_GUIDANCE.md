# Sources, evidence, and speaker notes

Each content slide may carry up to six author-supplied source references. A
reference has a label, optional evidence detail, and optional owner. Storyboard
Studio copies these fields into the slide's native PowerPoint speaker notes;
it does not fetch, verify, or invent citations.

The browser preview lets an author add a first source label and owner. More
references can be added by editing the versioned outline JSON locally. Model
output is always a draft: check statistics, names, and claims before sharing.
The notes use the explicit marker `author-supplied; not verified` to keep that
boundary visible after export.
