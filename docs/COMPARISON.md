# Why Storyboard Studio instead of Presenton or Slidev?

Choose the tool that owns your actual job.

| If you need… | Start with… | Why |
| --- | --- | --- |
| Broad AI presentation generation, many providers, images, charts, templates, and desktop/Docker distribution | [Presenton](https://github.com/presenton/presenton) | Its product surface is deliberately much broader. |
| Developer-authored presentations in Markdown with live coding and web-first delivery | [Slidev](https://github.com/slidevjs/slidev) | It is purpose-built for technical presentation workflows. |
| An offline, inspectable decision story with explicit evidence gaps, author dispositions, native PPTX export, and a verifiable local receipt | Storyboard Studio | This narrow review-before-render workflow is the product. |

Storyboard Studio is not trying to win a feature-count contest. It currently
has fewer visual and ingestion features than Presenton and is not a Markdown
presentation runtime like Slidev. Choose it when the difficult part is making a
decision, trade-off, evidence boundary, owner, and next step defensible before
the deck exists.
