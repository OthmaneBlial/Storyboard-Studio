# Shareable local template contract

A template folder can be committed, validated, and regenerated by anyone with
the project:

```text
examples/templates/<name>.json       # validated outline
examples/templates/<name>.contribution.json # public contribution manifest
examples/templates/<name>.md         # optional human-readable brief
docs/templates/<name>.md             # narrative and evidence assumptions
```

Public templates must contain synthetic or public content, pass the v1 schema,
and state which claims are placeholders. They must not contain API keys,
private client material, generated cache files, or hosted-service URLs.
`examples/templates/decision-brief.json` is the canonical example.

Public contributions use a strict manifest:

```json
{
  "schema_version": "1",
  "id": "decision-brief",
  "kind": "template",
  "content_path": "decision-brief.json",
  "content_origin": "synthetic",
  "license": "CC0-1.0",
  "attribution": "Storyboard Studio contributors",
  "description": "Synthetic fixture for the decision-brief workflow."
}
```

Run the contribution gate before opening a pull request:

```bash
storyboard validate-contribution \
  examples/templates/decision-brief.contribution.json \
  --output-dir output/contribution-validation
```

Or run the canonical repository target:

```bash
make validate-contribution
```

The command does not use a provider or make a network request. It validates:

- privacy: high-confidence credential prefixes, private-key blocks, personal
  absolute paths, non-example email addresses, and secret-like JSON fields;
- license: a bounded public license and CC0 for a synthetic public template;
- schema: explicit v1 presentation migration or a valid story-v2 document;
- rendering: a native PPTX plus the shared overflow result;
- attribution: the manifest and every referenced source/asset that carries
  content.

The generated `*.validation.json` is review evidence, not a guarantee that a
contributor owns the content or that every possible secret was detected. Human
review remains required. Public templates accept synthetic or public content;
do not contribute permissioned private material.
