# Shareable local template contract

A template folder can be committed and regenerated by anyone with the project:

```text
examples/templates/<name>.json       # validated outline
examples/templates/<name>.md         # optional human-readable brief
docs/templates/<name>.md             # narrative and evidence assumptions
```

Templates must contain synthetic or permissioned content, pass the v1 schema,
and state which claims are placeholders. They must not contain API keys,
private client material, generated cache files, or hosted-service URLs.
`examples/templates/decision-brief.json` is the canonical example.
