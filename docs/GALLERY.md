# Public gallery

The gallery contains only synthetic or permissioned examples. Every entry links
to its input outline and a reproducible export so visitors can inspect the
workflow without uploading private work.

## Private decision brief

[Open the example →](../gallery/decision-brief/)

The sequence names a decision, makes the trade-off visible, and ends with an
owned next step. It demonstrates the decision, comparison, and timeline blocks
and keeps all copy editable in PowerPoint.

To add an example, include a synthetic/permissioned JSON outline, a generated
PPTX, a viewer screenshot with alt text, and a short note describing the
evidence assumptions. Do not add client decks, credentials, tracking pixels,
or remote asset URLs.
