# Contributor recognition

Storyboard Studio credits work that actually ships. It does not use contribution
bait, automated star requests, invented testimonials, or vanity leaderboards.

## Shipped-contribution record

No external contribution has shipped since this public recognition ledger was
introduced. This statement is intentional: contributor names and outcomes are
never fabricated. The first qualifying entry will be added only after its pull
request is merged and the contributor has not opted out of public attribution.

## Release and showcase process

For each shipped external pull request:

1. Confirm the preferred GitHub handle/name and respect an attribution opt-out.
2. Add one release-note line linking the pull request and naming the concrete
   template, fixture, compatibility result, documentation, or code improvement.
3. Record the verification that passed; do not imply factual validation or an
   endorsement by the contributor.
4. If the work produced a public artifact, link it from `gallery/README.md` or
   the relevant documentation page.
5. Keep security reports private and never credit private reporters without
   explicit permission.

GitHub generated release notes may identify merged contributors, but maintainers
still review the wording and this ledger before publishing a release.
