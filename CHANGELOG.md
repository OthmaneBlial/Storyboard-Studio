# Changelog

## 0.3.0 — native preview

A new Rust workspace and Tauri desktop replace the retired application. Native
compilation preserves authored briefs, shares measured geometry between preview
and editable PPTX, and provides Doctor, package validation, portable image sidecars,
inspectable projects and hash receipts. Twelve themes, local brand logos, explicit
optional drafting, twenty synthetic galleries and local quality checks are included.

Prior releases remain available in Git tags. They do not certify current native
output, performance or platform compatibility. GitHub CI is disabled by owner request.
