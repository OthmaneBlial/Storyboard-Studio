# Support

## Before opening an issue

1. Try the documented [quick start](README.md#quick-start) with Python 3.10+
   and the local planner (`Use Gemini when available` unchecked).
2. Search existing issues and read the relevant section of `README.md`.
3. Reproduce with synthetic text. Remove API keys, customer material, and
   personal data from every report.

## Where to ask

- **Bug reports:** use the bug-report issue form with the version/commit,
  operating system, reproduction steps, and expected/actual result.
- **Feature ideas:** use the feature-request form and describe the presentation
  job it improves. A proposed implementation is helpful but not required.
- **Usage questions:** open an issue labelled `question` with a minimal,
  non-sensitive example. There is no hosted support inbox.
- **Security or privacy concerns:** follow `SECURITY.md`; do not use a public
  issue.

The project is maintained on a best-effort basis. A response is targeted within
14 days, but fixes and releases depend on reproducibility, impact, and
available maintainer time.
