This fictional research product is not a customer case study or investment claim.

```sh
cargo build --release
./target/release/storyboard build examples/startup-pitch.md \
  -o gallery/native/startup-pitch/deck.pptx --force
./target/release/storyboard verify gallery/native/startup-pitch/deck.receipt.json
```

The PNG is a real LibreOffice 26.8.0.3 PDF render on macOS 26.6. This confirms
that the 7-slide package imports and renders in that viewer; it does not certify
interactive editing in PowerPoint, Keynote or Google Slides.
