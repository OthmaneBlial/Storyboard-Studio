# Roadmap

## 0.3 — Native preview

Implemented and locally checked: typed stories/projects, Markdown and structured
briefs, actionable Doctor, measured shared geometry, editable OpenXML objects,
SVG preview, package validation, receipts, portable images, CLI, Tauri editor,
12 themes, local brand logos, opt-in draft providers and 20 synthetic gallery decks.

Release evidence remains explicit: independent viewer reports, desktop observations,
real benchmarks and platform installers must identify the actual tested artifact.
GitHub CI is disabled; the retired runtime/tooling is preserved only in Git history.

## Compatibility stabilization

Improve complex script shaping and font choices; expand chart data/label handling;
collect PowerPoint, Keynote and Slides observations for current native artifacts;
build and test macOS Intel, Windows x64 and Linux x64 installers on those platforms.
Keep failure messages conservative and preserve authored content.

## 1.0 contract

Freeze story/project/receipt versioning after compatibility evidence, document
explicit legacy migrations, and expand regression fixtures around real failures.
Consider additional renderers or extensions only when a concrete consumer needs
them. No speculative plugin runtime, hidden service or fabricated benchmark claims.
