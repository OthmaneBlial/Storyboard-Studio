# Roadmap

## Launch foundations

- [ ] Select and add an open-source license before accepting external code contributions.
- [ ] Add a short product demo video or GIF based on the live browser flow.
- [ ] Add a curated library of source-grounded brief templates.

## Better deck craft

- [ ] Offer deliberate layout variants with a visual preview before export.
- [ ] Add optional speaker notes and a source field for claims that require citation.
- [ ] Add image-provider integration only with clear cost, consent, and retention controls.

## Responsible growth

- [ ] Document a reverse-proxy deployment recipe with shared rate limiting for self-hosters.
- [ ] Add multilingual UI copy without weakening the local-first defaults.

Storyboard Studio will remain a focused deck-making tool. It is not planned as a cloud collaboration suite, a document database, or an automated research authority.
